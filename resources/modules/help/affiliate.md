# راهنمای سیستم افیلیت

## معرفی

سیستم افیلیت برای مدیریت پروژه‌های متحدین (بسلام و سایرین) و تنظیم‌های مربوط به لینک‌سازی و رهگیری فروش از طریق متحدین است.

## ویژگی‌ها

- اتصال به سرویس بسلام
- تنظیم کد معرف و کلید API
- مدیریت کمیسیون‌ها
- ردگیری فروش‌های افیلیت

## نکات تنظیم

> **💡 نکته:** برای فعال‌کردن افیلیت، باید حساب بسلام دارید و کد معرف و API key را وارد کنید.

# راهنمای تنظیمات پیامک

## معرفی ماژول

ماژول تنظیمات پیامک، اتصال به سرویس ملی‌پیامک (MeliPayamak) را پیکربندی می‌کند. این ماژول برای ارسال کدهای OTP (تأیید هویت) و اعلان‌های پیامکی استفاده می‌شود و با سیستم صف (Queue) یکپارچه است.

## ادغام با صف

وضعیت صف در بالای صفحه نمایش داده می‌شود:

- **صف فعال (database/redis):** پیامک‌ها پس از درخواست کاربر در صف قرار گرفته و در پس‌زمینه ارسال می‌شوند. برای محیط تولید توصیه می‌شود.
- **صف غیرفعال (sync):** پیامک‌ها به‌صورت همزمان ارسال می‌شوند که می‌تواند باعث کندی پاسخ به کاربر شود.

برای تغییر حالت صف، از ماژول **مدیریت صف‌ها** استفاده کنید.

## پیکربندی ملی‌پیامک

### آدرس وب‌سرویس (Endpoint)

آدرس پایه API ملی‌پیامک. توکن API به‌صورت خودکار به انتهای آدرس اضافه می‌شود:

```
{endpoint}/{token}
```

آدرس پیش‌فرض: `https://console.melipayamak.com/api/send/otp`

### توکن امنیتی (API Token)

توکن را از پنل ملی‌پیامک در بخش **تنظیمات > توکن API** دریافت کنید. این توکن به‌صورت رمزنگاری‌شده ذخیره می‌شود.

### شماره فرستنده

شماره اختصاصی ارسال پیامک. در صورت خالی بودن، از شماره پیش‌فرض پنل ملی‌پیامک استفاده می‌شود.

## تست ارسال پیامک

پس از ذخیره تنظیمات، با وارد کردن شماره موبایل مقصد (فرمت ۰۹xxxxxxxx) و متن پیام، می‌توانید اتصال به سرویس را آزمایش کنید. نتیجه شامل وضعیت HTTP، زمان پاسخ و پاسخ وب‌سرویس است.

## رفع مشکلات متداول

- **توکن تنظیم نشده:** از پنل ملی‌پیامک توکن معتبر دریافت کنید.
- **HTTP 401:** توکن اشتباه یا منقضی شده است.
- **HTTP 400:** شماره مقصد یا متن پیام اشتباه است.
- **Timeout:** سرور ملی‌پیامک در دسترس نیست یا Endpoint اشتباه است.

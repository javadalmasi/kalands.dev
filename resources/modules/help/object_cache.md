# راهنمای کامل ماژول Object Cache

## درایورهای Object Cache

Object Cache سطح برنامه برای کش کردن داده‌های PHP/Laravel است. می‌توانید درایور مناسب را انتخاب کنید.

### درایورهای موجود

- **File:** مناسب برای محیط توسعه، نیازی به سرویس جانبی ندارد
- **Redis:** پرسرعت، مناسب برای تولید، نیاز به سرور Redis دارد
- **Memcached:** پرسرعت، مناسب برای تولید، نیاز به سرور Memcached دارد
- **Database:** کش در دیتابیس، مناسب برای بارهای کم

## تنظیمات Redis

در صورت انتخاب Redis به عنوان درایور، می‌توانید تنظیمات اتصال را پیکربندی کنید.

### گزینه‌های اتصال

- **TCP:** اتصال از طریق پورت (پیش‌فرض: ۱۲۷.۰.۰.۱:۶۳۷۹)
- **Unix Socket:** اتصال از طریق فایل سوکت برای سرعت بالاتر
- **رمز عبور:** برای اتصال به سرورهای رمزدار
- **دیتابیس:** انتخاب دیتابیس Redis (پیش‌فرض: ۱)

## تست اتصال

این بخش برای بررسی صحت تنظیمات وضعیت اتصال به درایور فعال را نمایش می‌دهد.

## پاکسازی کش

با این عملیات تمام آیتم‌های ذخیره شده در object cache حذف می‌شوند. پس از پاکسازی، سیستم ممکن است کمی کندتر عمل کند.

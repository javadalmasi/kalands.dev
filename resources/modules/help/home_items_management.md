# راهنمای مدیریت آیتم‌های صفحه اصلی

## معرفی

این ماژول برای مدیریت اسلایدر اصلی، بنرهای دسته‌بندی و دیگر عناصر ویژوال صفحه اصلی استفاده می‌شود.

## بخش‌های اصلی

- اسلایدر اصلی: تصاویر اسلاید شو
- بنرهای دسته‌بندی: بنرهای مربوط به دسته‌بندی‌های محصولات
- ترتیب عناصر: درگ و رها کردن برای تنظیم ترتیب

## نکات طراحی

> **💡 نکته:** تصاویر بزرگ (1920x600 پیکسل) برای اسلایدر و تصاویر 400x300 برای بنرها توصیه می‌شود.

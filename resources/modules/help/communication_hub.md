# راهنمای ماژول جامع ارتباطی

## معرفی

ماژول جامع ارتباطی یک سیستم یکپارچه برای مدیریت تمامی کانال‌های ارسال (ایمیل عمومی، ایمیل تراکنشی و پیامک SMS) است. این ماژول تنظیمات سرویس‌دهندگان مختلف را مدیریت می‌کند.

## بخش‌های اصلی

| بخش | توضیح |
| --- | --- |
| SMTP عمومی | تنظیمات ارسال ایمیل درجه‌بندی‌شده و خبرنامه |
| SMTP تراکنشی | تنظیمات ارسال ایمیل‌های فوری و مهم |
| پیامک (SMS) | اتصال به سرویس‌دهندگان SMS مثل ملی‌پیامک |
| تنظیمات تست | ایمیل و شماره موبایل پیش‌فرض برای تست |

## نکات مهم

> **💡 نکته:** هنگام تغییر تنظیمات SMTP، حتما تست اتصال را انجام دهید. اگر ایمیل‌ها ارسال نمی‌شود، لاگ‌های سرویس را بررسی کنید.

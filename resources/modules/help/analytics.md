# راهنمای جامع ماژول آنالیزور

## معرفی

ماژول آنالیزور، سامانه گزارش حرفه‌ای بازدیدها و رفتار کاربران در پلتفرم کالندز است. داده‌ها از طریق اسکریپت رهگیری سمت کلاینت جمع‌آوری، در دیتابیس ذخیره و توسط Job تجمیعی پردازش می‌شوند.

ماژول دارای **۵ تب** اصلی است: داشبورد، زنده، آنالیز، اهداف، مدیریت.

---

## داشبورد

کارت‌های خلاصه وضعیت سایت در نگاه اول:

- **بازدید امروز / ۷ روز / ۳۰ روز**: مجموع pageviewها در هر بازه
- **کاربران زنده**: بازدیدکنندگان فعال در بازه پیش‌فرض ۵ دقیقه (به‌روزرسانی هر ۳۰ ثانیه)
- **بازدیدکننده یکتا**: مرورگرهای متفاوت بر اساس visitor_hash
- **جلسات امروز**: تعداد session های تشکیل‌شده
- **نرخ پرش**: درصد جلساتی با فقط ۱ pageview
- **مدت متوسط جلسه**: میانگین زمان بودن کاربر در سایت
- **نمودار بازدید**: روند روزانه در بازه انتخابی فیلتر
- **فعالیت‌ها**: توزیع نسبی بازدید / هدف / خطا

> ⚠️ داده‌های امروز بدون کش نمایش داده می‌شوند. برای بازه‌های گذشته کش ۶۰ ثانیه‌ای اعمال می‌شود.

---

## زنده

بازدیدکنندگان فعال را به صورت real-time نمایش می‌دهد (polling هر ۳۰ ثانیه).

**کارت‌های خلاصه:**
- تعداد کاربران زنده + نوسان نسبت به بار قبل
- بیشترین مرورگر در حال استفاده
- Goal های ۱۰ دقیقه اخیر
- غالب‌ترین منبع ورود

**نقشه زنده:**
- موقعیت تقریبی کاربران روی نقشه جهان (2D / 3D)
- لیست کشورهای فعال
- منابع ورود فعال (Search / UTM / Referrer)

**لیست کاربران:**
- ۱۰ سشن اخیر با IP، کشور، دستگاه، مرورگر، مسیر فعلی
- کلیک روی هر آیتم: مشاهده مسیر کامل جلسه (Journey)

> ⚠️ وقتی تب زنده فعال نباشد، Polling متوقف می‌شود تا مصرف منابع کاهش یابد.

---

## آنالیز

تحلیل عمیق ترافیک، جغرافیا، دستگاه، محتوا و کلمات کلیدی — همه در یک تب.

**بخش گزارش‌های ترافیکی:**
- **نقشه جهانی**: تراکم بازدید بر اساس کشور با رنگ‌بندی
- **کشورها**: پربازدیدترین کشورها با نوار درصدی
- **منابع ترافیک**: دامنه‌های ارجاع‌دهنده
- **موتورهای جستجو**: گوگل، بینگ، یاهو و ...
- **دستگاه‌ها**: دسکتاپ / موبایل / تبلت
- **برند دستگاه**: سامسونگ، اپل، شیائومی و ...
- **مرورگرها**: کروم، فایرفاکس، سافاری و ...
- **سیستم‌عامل**: ویندوز، اندروید، iOS و ...
- **UTM (بازاریابی)**: Source، Medium، Campaign به تفکیک

**بخش محتوا:**
- **صفحات پربازدید**: مسیر + عنوان + تعداد بازدید
- **محصولات پربازدید**: شناسه محصول + تعداد
- **دسته‌بندی‌های پربازدید**: کلید دسته + تعداد
- **فروشندگان پربازدید**: شناسه فروشنده + تعداد

> هر ردیف محتوا دارای آیکون لینک است که صفحه مربوطه را مستقیم باز می‌کند.

---

## اهداف

تحقق اهداف تعریف‌شده در سایت را نمایش می‌دهد. اهداف پیش‌فرض سیستم:

| هدف | کلید | توضیح |
|------|------|--------|
| کلیک دیجی‌کالا | `tr_dk` | کلیک روی لینک‌های افیلیت دیجی‌کالا |
| کلیک باسلام | `tr_bs` | کلیک روی لینک‌های افیلیت باسلام |

**کارت‌های مقایسه‌ای**: تعداد امروز + درصد تغییر نسبت به دیروز.

**جدول ۳۰ روز اخیر**: فهرست همه اهداف با تعداد تحقق.

> برای ثبت Goal در صفحات سایت، از attribute `data-analytics-goal="key"` روی المان HTML استفاده کنید.

## مدیریت

دو بخش مجزا در یک تب:

### تنظیمات ماژول

**ردیابی و جمع‌آوری داده:**
| تنظیم | پیش‌فرض | توضیح |
|--------|---------|--------|
| فعالسازی آنالیزور | روشن | کلید اصلی ثبت رویداد |
| اسکریپت رهگیری | روشن | ارسال pageview/goal با sendBeacon → fetch → pixel |
| Error Tracker | روشن | ثبت خطاهای JS (max ۵ در هر نشست) |
| Heartbeat | روشن | سیگنال ۳۰ ثانیه‌ای برای محاسبه مدت جلسه |
| هشدار خودکار | روشن | بررسی ناهنجاری پس از هر Aggregation |

**عملکرد و نگهداری:**
| فیلد | پیش‌فرض | توضیح |
|------|---------|--------|
| TTL کش گزارش‌ها | ۶۰ ثانیه | مدت cache ماندن نتایج API |
| پنجره کاربران زنده | ۵ دقیقه | بازه تشخیص کاربر زنده |
| مهلت پایان نشست | ۳۰ دقیقه | بدون فعالیت → جلسه بسته می‌شود |
| نگهداری رویداد خام | ۹۰ روز | پاکسازی خودکار رویدادهای قدیمی‌تر |
| نگهداری آمار تجمیعی | ۳۶۵ روز | مدت نگهداری آمار روزانه |

### نگهداری داده‌ها

**پاکسازی داده‌ها:**
- نوع داده: گزارش‌های خطا / جلسات قدیمی / همه رویدادها
- بازه زمانی: همه / ۱ ماه / ۳ ماه / ۶ ماه / ۱ سال

> ⚠️ عملیات پاکسازی غیرقابل بازگشت است.

**Export JSON**: خروجی از تنظیمات و آمار تجمیعی برای بکاپ یا انتقال.

**Import JSON**: درون‌ریزی فایل JSON برای بازگردانی آمار.

## فیلترها

فیلتر آنالیزور همیشه در بالای صفحه نمایان است و بر اساس تب فعال، فیلدهای مرتبط را نشان می‌دهد:

| تب | فیلدهای فعال |
|----|-------------|
| داشبورد | از/تا تاریخ، بازه، کشور، دستگاه، فعالیت، سورس، وضعیت جلسه |
| زنده | کشور، دستگاه، سورس، مرورگر، پلتفرم، وضعیت جلسه |
| آنالیز | از/تا تاریخ، بازه، مسیر، کشور، دستگاه، فعالیت، سورس، کمپین، مرورگر، پلتفرم |
| اهداف | از/تا تاریخ، بازه، Goal Key، سورس، کمپین، کشور، دستگاه |
| مدیریت | بدون فیلتر |

## اسکریپت رهگیری

اسکریپت به‌صورت خودکار در head بارگذاری می‌شود و سه لایه ارسال دارد:

1. **sendBeacon** — سریع‌ترین و مطمئن‌ترین، حتی پس از بسته شدن صفحه
2. **fetch** — fallback برای مرورگرهای بدون Beacon API
3. **Image pixel (1×1)** — آخرین fallback، حتی از پشت Ad-blocker

**رویدادهای ارسالی:**
- `pageview`: مسیر، عنوان، referrer، عمق اسکرول
- `goal`: کلید هدف + مقدار عددی
- `error`: پیام، منبع، شماره خط
- `heartbeat`: سیگنال زنده‌بودن کاربر

**ادغام با HTML:**
```html
<!-- ثبت Goal با کلیک -->
<button data-analytics-goal="my_goal_key" data-analytics-value="1">خرید</button>
```

## سیستم جلسات

هر بازدیدکننده یک session_id منحصربه‌فرد دریافت می‌کند:

- **جلسه جدید**: اولین بازدید یا بعد از timeout
- **Bounce**: جلسه‌ای با فقط ۱ pageview
- **مدت جلسه**: اختلاف زمان اولین و آخرین رویداد (با کمک Heartbeat)

---

## هشدارهای خودکار

پس از هر Aggregation Job (هر ۵ دقیقه)، شرایط زیر بررسی می‌شوند:

| شرط | توضیح |
|-----|--------|
| `gt` | بیشتر از مقدار مشخص |
| `lt` | کمتر از مقدار مشخص |
| `pct_change_gt` | درصد تغییر بیش از حد |
| `eq` | دقیقاً برابر |

## سوالات متداول

**❓ چرا داده‌های امروز با دیروز فرق دارد؟**
داده‌های امروز بدون کش نمایش می‌شوند. بازه‌های گذشته تا ۶۰ ثانیه cache می‌شوند.

**❓ چرا نقشه زنده به‌روز نمی‌شود؟**
Polling فقط وقتی تب زنده فعال است اجرا می‌شود. اگر به تب دیگری رفتید، Polling متوقف می‌شود.

**❓ تفاوت بازدید و بازدیدکننده یکتا چیست؟**
بازدید = تعداد کل pageviewها. یکتا = مرورگرهای متفاوت بر اساس visitor_hash.

**❓ چگونه داده‌های قدیمی را پاک کنم؟**
به تب مدیریت → نگهداری داده‌ها بروید. نوع داده و بازه زمانی را انتخاب کنید. ⚠️ غیرقابل بازگشت.

**❓ چرا خطاهای JavaScript ثبت نمی‌شوند؟**
مطمئن شوید Error Tracker در تنظیمات روشن باشد. محدودیت ۵ خطا در هر نشست اعمال می‌شود.

**❓ Goal های افیلیت کجا نمایش داده می‌شوند؟**
تب اهداف — کارت‌های کلیک دیجی‌کالا و باسلام آمار روزانه را نشان می‌دهند.

## جزئیات فنی

| مورد | توضیح |
|------|--------|
| Endpoint جمع‌آوری | `POST /api/analytics/collect` |
| Aggregation Job | هر ۵ دقیقه (uniqueFor: 300s) |
| Heartbeat interval | ۳۰ ثانیه |
| کش گزارش‌ها | ۶۰ ثانیه (امروز بدون کش) |
| Session timeout | ۳۰ دقیقه (قابل تنظیم) |
| ضد Ad-blocker | سه لایه sendBeacon → fetch → pixel |
| GeoIP | MaxMind Country |
| شناسایی دستگاه | MobileDetectLib (برند، مرورگر، پلتفرم) |
| محدودیت خطا | ۵ خطا در هر نشست |
| Batch ارسال | حداکثر ۱۰ رویداد در هر درخواست |

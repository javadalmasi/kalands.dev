# راهنمای کامل مدیریت صف‌ها

## معرفی ماژول

ماژول مدیریت صف، سامانه پردازش کارهای توالی در پس‌زمینه است. این سامانه برای قطعه کردن کارهای سنگین (مانند ایمپورت داده، بروزرسانی GeoIP) و بهبود سرعت وب‌سایت استفاده می‌شود.

## حالت‌های پردازش

- **Cron Job:** برای هاست‌های اشتراکی (Shared Hosting) مناسب است. با فراخوانی دوره‌ای URL صف پردازش می‌شود.
- **Artisan Worker:** برای سرورهای اختصاصی (Dedicated/VPS) مناسب است. پردازش توسط پروسه `queue:work` انجام می‌شود.

## درایورهای صف

- **sync:** پردازش فوری (بدون صف‌زدن) - برای تست مناسب است
- **database:** ذخیره در دیتابیس - ساده و قابل اعتماد
- **redis:** ذخیره در Redis - سریع و برای سرورهای تولید

## نکات امنیتی

- توکن Cron باید محرمانه بماند و در دسترسی عمومی نباشد
- تمامی endpointهای صف نیاز به توکن برای دسترسی دارند
- در صورت تغییر توکن، دستور Cron را نیز به‌روز کنید

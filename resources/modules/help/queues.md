# راهنمای مدیریت صف‌ها

## معرفی

صف‌ها (Queue) برای پردازش کارهای طولانی مدت به صورت ناهمزمان استفاده می‌شوند تا سرویس وب کند نشود.

## حالت‌های صف

| حالت | توضیح |
| --- | --- |
| Sync | فوری و درون‌فرآیند (توسعه) |
| Database | ذخیره در دیتابیس (تولید) |
| Redis | ذخیره در Redis (سریع‌تر) |

## مراقبت

> **⚠️ هشدار:** در تولید، حتما Cron Job برای اجرای queue:work فعال کنید تا کارهای صف پردازش شوند.
